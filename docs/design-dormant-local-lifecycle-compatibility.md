# Dormant trusted-local lifecycle compatibility inventory

Status: implemented 2026-08-09. This inventory distinguishes current authority
from bytes retained only so older graphs fail closed. “Retained” never means
that a legacy row may be scheduled again.

## Preserved boundaries

This cleanup does **not** alter federation dependency resolution,
remote-provider scoping, read-only workers, immutable completion/review evidence,
receipt-backed terminal completion, attempt ownership, or lifecycle fences. Old
bytes are either loaded without semantic inference or rejected by an already
explicit retired command; no replacement broker, allowlist, status, or protocol
was introduced.
